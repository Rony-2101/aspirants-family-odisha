Upload admin.html, admin.css, and admin.js to the root of your GitHub Pages repository. This uses the existing Supabase jobs table and email/password auth. The homepage must separately be connected to read active jobs; adding a vacancy here does not automatically show it on the homepage until that integration is added. Never put a Supabase secret/service_role key in browser code. Restrict the authenticated write policy to your own admin UID before public use.
